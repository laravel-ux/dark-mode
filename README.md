Laravel UX Dark Mode
======================

Introduction
---------------

Dark mode support for Laravel applications using Laravel UX and Livewire. The package provides an initialization
directive and a session-backed Livewire toggle.

Documentation
----------------

Documentation for Laravel UX Dark Mode can be found on the [Laravel UX website](https://laravel-ux.com/docs/dark-mode).
